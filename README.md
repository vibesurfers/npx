# @_scavengers/cli

Random ASCII art generator featuring cyber-punk scavenger animals.

## Usage

```bash
npx @_scavengers/cli
```

## What is this?

Run the command and get a random ASCII art scavenger - raccoons, ravens, mice, crows, wolves, hyenas, and more - all in cyber-punk style doing bizarre things.
